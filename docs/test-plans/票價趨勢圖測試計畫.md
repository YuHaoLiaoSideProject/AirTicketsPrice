## 2. 前端單元測試（資料邏輯模組）

> 說明：本專案無後端，「資料組裝 / 錯誤處理 / 商業規則」邏輯皆位於前端資料層模組（`fetchIndex` / `fetchTrips` / `aggregateWeekly` / `calcAverage` / `calcDiffPct` / `filterRange` / `cache` / `isStale` / `detectPeak` 等純函式），故 @error-handling 與 @business-rules 場景由本層單元測試覆蓋。

### 2.1 資料組裝與聚合模組

| # | 測試名稱 | Given | When | Then |
|---|---------|-------|------|------|
| F-01 | 每週價格取該週所有航班最低價（BDD: 每週價格取該週所有航班最低價） | 某一週有東京 3 班（JX 800=32296 / JX 802=46072 / JX 804=33880） | 執行每週聚合 | 該週價格點 = 32296（最低值） |
| F-02 | 平均線以全域 40 週計算（BDD: 平均線以全域 40 週計算且不隨篩選漂移） | 東京 40 週每週最低價資料 | 計算平均線 | 平均線 = 全部 40 週每週最低價之平均 |
| F-03 | 差幅計算以全域平均為基準（BDD: 平均線以全域 40 週計算且不隨篩選漂移） | 全域平均 A、該週價格 P | 計算差幅 | 差幅 = (P − A) / A，正值表示比平均貴、負值表示比平均便宜 |
| F-04 | 日期範圍篩選週數映射（BDD: 篩選日期範圍） | 40 週資料 | 依範圍篩選 | 3 個月 → 12 週；6 個月 → 24 週；12 個月 → 40 週；全部 → 40 週 |
| F-05 | 最低價標記依可見範圍重算（BDD: 篩選日期範圍） | 已篩選至 3 個月（12 週）範圍 | 計算範圍內最低價標記 | 標記 = 可見 12 週內之最小值（可能與全域最低價不同） |
| F-06 | 平均線不隨範圍漂移（BDD: 篩選日期範圍） | 篩選範圍為 3 個月 | 輸出圖表資料 | 平均線仍為全域 40 週平均值（資料值與未篩選時相同） |
| F-07 | 航班模式切換資料組裝（BDD: 切換航班顯示模式） | 東京 40 週 × 3 航班資料 | 切換為「JX 800」模式 | 只輸出 JX 800 的 40 週價格線；模式標註為「JX 800」；切回「全部」輸出每週最低價主線 |
| F-08 | 缺資料週產生斷點（BDD: 某週 trip 檔缺失顯示斷點與「本週無資料」） | 第 20 週 trip 檔缺失 | 聚合 40 週資料 | 第 20 週價格 = null（斷點），其餘週正常 |
| F-09 | 售罄週標示與斷線（BDD: 售罄週標示） | 第 30 週全部航班 status 為售罄（price_total 無效或標記 sold_out） | 聚合資料 | 第 30 週標示「售罄」且曲線在該週斷開 |
| F-10 | 資料過舊判定（BDD: 資料過舊顯示黃色警示） | generated_at 距今 15 天 | 判定過舊 | isStale = true（>14 天）；邊界：恰好 14 天 → false |
| F-11 | 空資料狀態判定（BDD: 無任何 trip 資料顯示空狀態） | index.json 的 trips 清單為空 | 判定資料狀態 | 回傳 empty 狀態（顯示「尚無價格資料，每週五更新」） |
| F-12 | 網域來源判定（BDD: CORS 或網域來源問題） | 目前 location.origin 不在允許清單 | 判定來源 | 回傳 forbidden 錯誤（提示改用 GitHub Pages 網址） |
| F-13 | 航線資料快取（BDD: 切換航線時已載入資料不重複下載） | 東京航線已載入並快取 | 再次請求東京航線 | 命中快取，不觸發新的 fetch |
| F-14 | 預設航線選中第一條（BDD: 開啟頁面顯示頁首與預設航線 tab） | index.json routes = [TPE-KIX, TPE-NRT] | 初始化應用狀態 | 預設選中 CONFIG.ROUTES 第一條（東京 TPE-NRT，不依 index 順序） |
| F-15 | 更新時間格式化（BDD: 開啟頁面顯示頁首與預設航線 tab） | generated_at = "2026-08-14T13:19:34.000Z" | 格式化顯示 | 顯示可讀的資料更新時間字串 |
| F-16 | 旺季區間判定（BDD: 趨勢圖標記與圖例一目了然） | 過年區間 2027-01-30~02-06、櫻花季 2027-03-27~04-03 | 判定某週出發日期 | 落在區間內的週被標記為對應旺季區塊（過年 / 櫻花季） |
| F-17 | Summary 三卡計算（BDD: Summary 三卡隨範圍與航線更新） | 東京資料、範圍 3 個月 | 計算 Summary | 最便宜週 = 範圍內最低價週 + 金額；平均價 = 全域平均；旺季高峰 = 旺季區間最高價，名稱對應正確區塊 |
| F-18 | 價格定義與時間範圍限制（BDD: 價格定義與時間範圍限制） | 資料模型（僅經濟艙、星宇直營、來回總價 TWD） | 讀取並驗證資料欄位 | 價格為去程週六→回程下週日來回總價 TWD；僅輸出未來 40 週範圍；不提供艙等/人數/單程/其他航司篩選 |

### 2.2 補充測試（智能補充：邊界 / 依賴失敗 / 並發 / 生命週期）

| # | 測試名稱 | Given | When | Then |
|---|---------|-------|------|------|
| F-19 | 範圍參數邊界值 | 範圍參數為空字串、負數、或超過 40 週（如 999 個月） | 執行 filterRange | 回退為安全預設（空/負 → 全部 40 週；>40 週 → 40 週），不產生例外 |
| F-20 | 部分 trip 檔失敗時其餘週正常 | 東京 40 檔中 3 檔 fetch 失敗 | 聚合資料 | 失敗週為斷點，其餘 37 週正常繪製，不整頁失敗 |
| F-21 | 快速切換航線時忽略過期回應 | 使用者快速切東京→大阪→東京 | 各請求依序回應（後到者先回） | 只套用最新航線的資料，過期回應被丟棄（request token / AbortController） |
| F-22 | 元件生命週期：unmount 中止進行中 fetch | 頁面元件在資料載入完成前被銷毀 | 元件 unmount | 進行中的 fetch 被 abort，無記憶體洩漏、無 post-unmount 狀態更新 |

## 3. 整合測試（Playwright route interception）

> 使用 Playwright 的 `route` 攔截 `api/index.json` 與 `api/trips/*.json`，注入真實 fixture 或 mock，驗證資料管線與元件整合行為。

| # | 測試名稱 | Given | When | Then |
|---|---------|-------|------|------|
| INT-01 | 資料管線端對端組裝（BDD: 檢視東京 40 週趨勢圖） | 以真實 api/ fixture 提供 index.json + 40 個東京 trip 檔 | 開啟頁面並等待載入 | 圖表資料含 40 個週點，單位 TWD，日期依序且正確 |
| INT-02 | 並行載入效能（BDD: 檢視東京 40 週趨勢圖） | 本機靜態伺服器提供全部 trip 檔 | 首次載入頁面 | 3 秒內出現第一張圖表；重訪時 <1 秒（快取） |
| INT-03 | index.json 失敗 → 重試 → 恢復（BDD: index.json 載入失敗顯示全頁錯誤卡並可重試） | 首次 route 回傳 500，重試 route 回傳 200 | 開啟頁面 → 點「重試」 | 首次顯示全頁錯誤卡；重試後頁面載入 index.json 並顯示圖表 |
| INT-04 | 切換航線保留設定與航班回退（BDD: 切換航線並保留設定） | 東京、模式 JX 800、範圍 3 個月 | 切換到大阪 KIX tab | 圖表資料切為大阪；範圍仍 3 個月；航班模式回退「全部（每週最低價）」（JX 800 不存在於大阪，航班選項重建為 JX 820 / JX 822） |
| INT-05 | 快取不重複下載（BDD: 切換航線時已載入資料不重複下載） | 東京已載入 | 切大阪再切回東京，計數 trips fetch 次數 | 東京 trips 只被 fetch 一次（第一次載入），切回時不重新請求 |
| INT-06 | hover tooltip 資料完整性（BDD: hover 查看單週價格細節） | 圖表已渲染東京 40 週 | hover 某資料點 | tooltip 含出發日期、回程日期、價格（TWD）、與平均價差幅（N%）、最低價航班號 |
| INT-07 | 範圍切換後平均線資料不變（BDD: 平均線以全域 40 週計算且不隨篩選漂移） | 東京全部 40 週 | 切換範圍 3 個月/6 個月/全部 | 平均線資料值於三種範圍下完全一致（全域平均） |
| INT-08 | Summary 與圖表資料同步（BDD: Summary 三卡隨範圍與航線更新） | 東京、範圍 3 個月 | 切換範圍為全部、再切航線到大阪 | Summary 三卡（最便宜週/平均價/旺季高峰）與圖表、範圍、航線同步更新 |
