## 2. 設計原則

1. **每週最低價為主線** — 核心目的「找最便宜出發週」，曲線直接呈現最低價，不畫各航班平均造成混淆。
2. **全域平均基準不漂移** — 篩選日期範圍時平均線維持全域，避免比較基準跳動誤導決策。
3. **漸進式揭露** — 40 個資料點不塞滿資訊；細節（差幅、航班）於 hover/focus 顯示。
4. **語意色一致** — accent=主線、warning=平均、danger=最低價與旺季、success=比平均便宜。
5. **觸控與鍵盤優先** — mobile 控制 44px；資料點可 Tab 聚焦讀取 tooltip。

## 3. 目標設計（與 Mockup 對應）

單頁儀表板：頁首（標題＋更新時間 badge）→ 航線 tab → 工具列（航班 select／日期範圍／圖例）→ SVG 趨勢圖（折線＋平均線＋最低價標記＋旺季區塊）→ Summary 三卡（最便宜週／全域平均／旺季高峰）。

| 區塊 | 內容 | 互動 |
|------|------|------|
| 頁首 | 標題、資料更新時間（generated_at） | 資料過舊(>14 天)轉黃色警示 |
| 航線 tab | 東京 TPE-NRT／大阪 TPE-KIX | 切換保留航班與範圍設定 |
| 航班 select | 全部（每週最低價）／個別航班 | 個別航班缺資料週顯示斷點 |
| 日期範圍 | 3 個月(12 週)／6 個月(24 週)／全部(40 週) | 最低價標記隨範圍重算 |
| 趨勢圖 | 折線＋平均虛線＋紅點最低價＋旺季底色 | hover/focus 顯示 tooltip |
| Summary | 最便宜週／平均價／旺季高峰 | 隨範圍與航線即時更新 |

## 4. 狀態矩陣

（完整版於 Mockup HTML 內，含視覺樣本）

| 狀態 | 視覺 | 互動 |
|------|------|------|
| 一般 | 折線＋平均虛線＋最低價紅點＋旺季底色 | hover 資料點看 tooltip |
| Hover/Focus | 點放大＋tooltip | 滑鼠與鍵盤（tabindex=0）皆可讀 |
| 載入中 | 骨架＋spinner | 工具列 disabled |
| 空資料 | 空狀態插圖＋「每週五更新」 | 無 |
| 載入失敗 | 錯誤卡＋重試按鈕 | 點重試重新 fetch |
| 缺資料週 | 折線斷點 | hover 顯示「本週無資料」 |
| 售罄週 | X 軸下方「售罄」灰字 | 無 |
| 資料過舊 | 頁首黃色警示條 | 無 |

## 5. 無障礙（WCAG）

- **1.4.1** 不單靠顏色：旺季有文字標籤、tooltip 有差幅數字、圖例有文字。
- **2.4.7** focus ring：控制元件 3px accent；資料點 focus 等同 hover。
- **2.5.5** 觸控目標：mobile 一律 44px。
- **4.1.2** 狀態語意：tab 用 `aria-selected`、範圍按鈕用 `aria-pressed`、圖表 `role="img"`＋`aria-label`。
- **動畫**：僅 tooltip 淡入與載入骨架；`prefers-reduced-motion` 下全停。

## 7. 實作建議

1. **圖表庫**：Chart.js 或 ECharts 皆可；語意色對應本文件 token。折線缺資料週以 `spanGaps:false` 斷點。
2. **資料組裝**：`index.json` 列出 trips → 並行 fetch `api/trips/*.json` → 每航班取 history 最新一筆 → 每週最低價 = min。建議整併為單一「每週聚合」模組供圖表與 Summary 共用。
3. **快取**：fetch 結果存記憶體；切航線不重載已取資料。
4. **更新時間**：讀 `index.json → generated_at`；超過 14 天切黃色警示。
5. **旺季區間**：以出發日期判斷（2027 過年 1/30–2/6、櫻花 3/27–4/3），寫為設定檔隨年調整。
