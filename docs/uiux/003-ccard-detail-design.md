# 003 — ccard 點擊詳情面板設計規格

> **類型**：完整規格（非比較稿）
> **範圍**：點擊「每週票價變動」卡片後的詳情面板（航班比較 + 歷史走勢）
> **建立日期**：2026-09-12

---

## 1. 現況審計

| # | 問題 | 嚴重度 | 位置 |
|---|------|--------|------|
| 1 | ccard 無 click handler，是純展示卡片 | P1 | `app.js` ccard 渲染段 |
| 2 | 點擊後無處顯示「航班比較 + 歷史走勢」 | P1 | 缺少 detail modal/panel |
| 3 | 資料少時（僅 1 個航班 / 1 次抓取）無降級設計 | P2 | 需新增 |

### 資料結構分析

- 每個出發日的航班數量 **因航線而異**：
  - **1 班**：CTS（札幌）、FUK（福岡）、NGO（名古屋）、PUS（釜山）
  - **2 班**：BKK（曼谷）、KIX（大阪）、OKA（沖繩）、SGN（胡志明）
  - **3 班**：NRT（東京）
- 每個航班在不同抓取日期有價格記錄（11 個 data file = 11 次抓取）
- 資料少的邊界情況：
  - 僅 1 個航班（航線本身只有單航班）
  - 僅 1 次抓取（首次載入，無歷史比較）
  - 售罄（status = "sold_out"）
- **設計原則**：航班數量不寫死，動態渲染（1～N 班）

---

## 2. 設計原則

1. **漸進式揭露**：ccard 顯示摘要，點擊後展開詳情，不增加首頁負擔
2. **資料少不失控**：任何資料量都有對應的降級 UI，不白屏、不錯位
3. **上下文保持**：詳情面板不跳離頁面，以 overlay/modal 呈現，ESC 或點外部可關閉
4. **語意化圖示**：漲跌用箭頭 + 色彩雙重傳達（WCAG 1.4.1）
5. **觸控優先**：Mobile 關閉按鈕 ≥ 44px，面板可上下滑動

---

## 3. 目標設計

### 3.1 觸發行為

- 點擊 `.ccard` → 開啟詳情 modal
- 按 `ESC` 或點擊 backdrop → 關閉
- Mobile：面板從底部滑入（sheet style）

### 3.2 面板結構

```
┌─────────────────────────────────────────┐
│  ✕  09/12 出發 → 09/20 回程            │  ← Header（日期 + 關閉）
├─────────────────────────────────────────┤
│  📊 航班價格比較                         │  ← Section 1: 航班比較
│  ┌───────────┬───────────┬──────────┐   │
│  │ 航班      │ 價格      │ 比平均   │   │
│  ├───────────┼───────────┼──────────┤   │
│  │ JX 741    │ NT$23,027 │ +43% 🔴  │   │
│  │ JX 745    │ NT$15,876 │ -1%  🟢  │   │

├─────────────────────────────────────────┤
│  📈 歷史價格走勢                         │  ← Section 2: 歷史走勢
│  ┌─────────────────────────────────┐   │
│  │     ·····                       │   │  ← Mini chart（SVG）
│  │   ··    ···                     │   │

│  │·                 ···            │   │
```

### 3.3 Section 1：航班價格比較

**正常狀態（1+ 航班）**：
- 表格呈現，欄位：航班、**時間**（起飛→抵達）、價格、比平均差異百分比
- 時間資料來源：`outbound_departure_time` / `outbound_arrival_time`
- 最低價航班高亮（綠色背景 + 「最低」badge）
- 排序：價格由低到高
- 航班數量動態：1 班顯示 1 列、2 班顯示 2 列、3 班顯示 3 列…

**資料少降級**：
- 僅 1 航班 → 表格僅 1 列（或改為單行卡片，視版面）
- 售罄 → 航班列表仍可見（灰色），價格欄顯示「已售罄」
- 無價格 → 顯示「暫無報價」佔位

### 3.4 Section 2：歷史價格走勢

**正常狀態（≥ 2 次抓取）**：
- Mini 折線圖（SVG），X 軸為抓取日期，Y 軸為價格
- 標記最低點（綠色圓點 + 價格標籤）
- 標記最新抓取點（藍色圓點）
- 圖表下方顯示統計摘要：最低 / 最高 / 降幅

**資料少降級**：
- 僅 1 次抓取 → 圖表顯示單點（無折線），下方提示「僅 1 個資料點，尚無走勢可比較」
- 僅 2 次抓取 → 兩點連線，仍顯示圖表
- 所有抓取價格相同 → 顯示水平線 + 「價格穩定」

### 3.5 Footer：資料說明

- 顯示抓取次數與日期範圍
- 例如：「資料來自 4 次抓取（8/22 ~ 9/11）」

## 4. 狀態矩陣

| 狀態 | 視覺 | 互動 |
|------|------|------|
| 正常（多航班 + 多次抓取） | 完整表格 + 折線圖 | 點擊 ccard 開啟 |
| 僅 1 航班 | 單行卡片，無表格 | 同上 |
| 僅 1 次抓取 | 圖表顯示單點（無折線）+ 提示「尚無走勢可比較」 | 同上 |
| 售罄 | 「已售罄」佔位 | 同上，圖表仍顯示歷史 |
| 載入中 | 骨架屏（skeleton） | 等待資料載入 |
| 錯誤 | 錯誤提示 + 重試按鈕 | 點重試重新載入 |

## 6. 無障礙

- Modal 開啟時 focus 移入，關閉時回到觸發 ccard（`aria-modal="true"`）
- 關閉按鈕 `aria-label="關閉詳情"`
- 表格使用 `<table>` 語意，含 `<th>` 表頭
- 圖表 `role="img"` + `aria-label` 描述趨勢
- 漲跌不只用顏色，同時用箭頭符號（↑↓）+ 文字（漲/降）

## 7. 實作建議

1. **DOM 結構**：新增 `#detailModal` 容器，與 `.page` 同層
2. **資料取得**：點擊 ccard 時，從 `routeCache` 取得該週資料；歷史資料需從 `CACHE.units` 中同一 `outbound_date` 的不同抓取日期聚合
3. **Mini chart**：SVG 折線圖，寬度 100%、高度 120px，複用既有 `svgEl` 工具函式
4. **動畫**：`prefers-reduced-motion: reduce` 時取消滑入動畫
5. **Z-index**：Modal 層級需高於 tooltip（目前 tip z-index: 5），建議 `z-index: 100`
