狀態矩陣

狀態視覺互動
正常（多航班 + 多次抓取）完整航班表格 + 折線圖 + 統計摘要點擊 ccard 開啟 modal
僅 1 航班隱藏表格 → 單行卡片（航班 + 價格 + 比平均）；或保留 1 列表格同上
3+ 航班完整表格，按價格排序；最低價綠色高亮同上
僅 1 次抓取隱藏圖表 → 「首次抓取，尚無歷史比較」同上
售罄航班行顯示「已售罄」灰色文字，圖表仍顯示歷史同上
無價格資料「暫無報價」佔位同上
全部航班售罄顯示「本週已售罄」，航班列表仍可見（灰色）同上
ESC / 點 backdropModal 淡出關閉焦點回到觸發 ccard
無障礙：Modal 開啟時 aria-modal="true"，focus 移入；關閉時 focus 回到觸發 ccard。表格使用語意 <table>。漲跌不只用顏色，同時用 ↑↓ 箭頭 + 文字。
