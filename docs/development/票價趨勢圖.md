## 概述

讓公開訪客一眼看出星宇航空各航線「未來 40 週中哪週出發最便宜」，以最低價標記、全域平均線與旺季提示輔助購買決策；純靜態前端，零建置、零依賴，commit 即上線。核心包含：

1. **資料層（api）**：fetch `../api/index.json`（`cache:'no-cache'`）→ Promise pool（concurrency 8）並行載入該航線 40 個 trip 檔 → `Map<url, json>` 記憶體快取；載入進度顯示於頁首。
2. **聚合模組（aggregate）**：純函式，把 trip 檔組出「每週最低價」系列（缺資料週 / 售罄週標記）、全域平均、差幅、範圍篩選、最低價標記、旺季判定、過舊判定、Summary 計算；圖表與 Summary 共用同一份資料，單點維護。
3. **圖表層（chart）**：手繪 inline SVG（移植 mockup 繪圖邏輯）：折線（斷點分段）、全域平均虛線、最低價紅點＋金額標籤、旺季底色區塊＋文字標籤、售罄週標示、Y 軸統一 12K–42K。
4. **互動層（ui）**：航線 tab（東京/大阪）、航班 select（全部/個別）、日期範圍 segmented（3/6/12 個月/全部）、hover/focus tooltip（日期/價格/差幅/航班號）、Summary 三卡；切換航線保留航班與範圍設定。
5. **狀態處理（states）**：載入骨架＋spinner、全頁錯誤卡＋重試＋錯誤代碼、資料過舊(>14 天)黃色警示、空狀態；工具列載入中 disabled。
6. **驗證腳本（tests/e2e_smoke.py）**：Python Playwright headless 冒煙（真實資料）＋ route 攔截 mocked 邊界案例＋375px mobile＋console/page error 品質閘。

章節取捨（依功能類型）：純前端功能，無後端實作章節（§1 略）；無新增 API endpoint（§3 略，既有靜態 API 消費合約置於 §4）；跨 API/前端資料流 → §4；新 UI 元件與圖表樣式 → §7；部署設定（GitHub Pages 路徑 + 選配 CI）→ §9。

商業規則對應（BDD @business-rules）：

| 規則 | 實作位置 |
|------|---------|
| 每週價格 = 該週所有航班最低價（非各航班平均） | `aggregateWeek`（F-01, E2E-20） |
| 平均線 = 全域 40 週最低價之平均，**不隨範圍篩選漂移** | `globalAverage`（F-02, F-06, INT-07） |

| 價格定義：經濟艙、星宇直營、去程週六→回程下週日來回總價 TWD；僅 40 週；無艙等/人數/單程/他航篩選 | 資料模型（§4）＋不提供對應控制項（F-18, E2E-23） |

### 2.8 狀態處理（states）

| 狀態 | 觸發 | 行為 |
|------|------|------|
| 載入中 | loadRoute 進行中 | 圖表區骨架＋spinner；頁首進度「已載入 N/40」；工具列全部 `disabled`（E2E-14） |
| 空資料 | `index.trips` 為空 | 空狀態插圖＋「尚無價格資料，每週五更新」；無圖表（F-11, E2E-12） |
| 載入失敗 | `fetchIndex` 失敗 | 全頁錯誤卡「資料載入失敗」＋「重試」按鈕；重試重新走完整載入流程；連續失敗時顯示錯誤代碼（`ERR_INDEX_FETCH`=index HTTP 非 2xx / `ERR_INDEX_INVALID`=shape 驗證失敗 / `ERR_NETWORK`=fetch 網路層錯誤（TypeError）/ `ERR_ORIGIN_FORBIDDEN`=來源檢查失敗）（INT-03, E2E-08, MAN-05） |
| 來源被拒 | `checkOrigin` 失敗 | 錯誤卡＋提示「請改用 GitHub Pages 網址開啟」＋重試（F-12, E2E-13, MAN-04） |

| 缺資料週 | trip 檔 404 / 無 flights | 折線斷點＋gap-dot；hover「本週無資料」（F-08, F-20, E2E-09） |

| 更新時間 badge | 正常 | 綠底「資料更新 YYYY-MM-DD · 每週五更新」（`generated_at` 取日期部分） |

## 4. 資料流

跨「GitHub Pages 靜態 API → 瀏覽器前端」的資料管線（本專案無後端，資料流即此消費管線）。

```
GitHub Pages (Deploy from main / root)
  └── api/
      ├── index.json            ← 1. fetch（{cache:'no-cache'} 重新驗證）
      ├── latest.json           ← 本次功能不消費（保留給其他用途）
      └── trips/*.json (80 檔)  ← 2. 依 index.trips 並行 fetch（concurrency 8）
                                       │ 每完成一檔 → 進度「已載入 N/40」
                                       │ 成功 → Map<url, json> 記憶體快取
                                       ▼
     3. aggregateWeekly()：每航班 history 最新一筆 price_total（status Available 才有效）
        → 每週最低價 min / 缺資料週 null / 售罄週 sold_out
        → globalAverage（全域 40 週）→ minMark（可見範圍）→ detectPeak（旺季）
                                       ▼
     4. buildChart() → SVG 折線/平均虛線/最低價標記/旺季區塊/售罄
        renderSummary() → 三卡         互動（航班/範圍/航線切換）全部吃記憶體資料，<1s 重繪
```

### 4.1 消費合約（既有靜態 API，本功能不新增 endpoint）

**`GET ../api/index.json`**（相對 repo root；頁面在 `web/` 所以為 `../api/index.json`）

| 欄位 | 型別 | 用途 |
|------|------|------|
| `generated_at` | string (ISO) | 頁首更新時間 badge；`isStale` 判斷 >14 天警示 |
| `routes` | string[] | 存在性檢查（前端以 CONFIG.ROUTES 為顯示順序與來源） |
| `trips` | string[] | 本航線 trip 檔 URL 清單（依檔名前綴 `TPE-NRT_` / `TPE-KIX_` 分航線） |
| `trip_count` / `files` / `latest` | — | 本次不消費 |

**`GET ../api/trips/{route}_{dep}_{ret}.json`**（單週單航線）

| 欄位 | 型別 | 用途 |
|------|------|------|
| `route_id` / `outbound_date` / `return_date` | string | 週資料 `d` / `r`（去程週六、回程下週日） |
| `flights[].outbound_flight_no` | string | 航班號（原值含空格如 `"JX 800"`，工具列/標籤照用） |
| `flights[].history[]` | array | 取 `scraped_at` 最新一筆的 `price_total`（TWD）與 `status` |
| `history[].status` | string | `"Available"` 才視為有效價格；否則該航班無效價 |

### 4.2 載入策略（D4）

1. `fetchIndex`：僅 index.json 帶 `{cache:'no-cache'}`；trip 檔走瀏覽器預設快取（ETag 重新驗證），確保每週更新可見又不犧牲效能。
2. **並行但不突發**：Promise pool，同時最多 8 個 fetch；80 小檔全量 <70KB，一次全載最省事。
3. **記憶體快取**：`routeCache: Map<routeId, Week[]>`；切航線回東京直接繪圖（第二次 <1s 驗收）。
4. **競態防護（F-21）**：`loadToken` 序號——快速切航線時只套用最新航線資料，過期回應丟棄；`AbortController` 於重新載入時中止進行中 fetch（F-22）。

### 4.3 資料流對應 BDD 情境

| BDD 情境 | 資料流環節 |
|---------|-----------|
| 開啟頁面顯示頁首與預設航線 tab | 1 → 2（預設東京 TPE-NRT，F-14/F-15） |
| 檢視東京 40 週趨勢圖 | 2 → 3 → 4（INT-01/INT-02/E2E-02） |
| index.json 載入失敗→重試 | 1 失敗 → 全頁錯誤卡（INT-03/E2E-08） |
| 缺資料週 / 售罄週 | 2 中該檔 null → 3 標記 → 4 斷點/售罄文字（E2E-09/E2E-10） |
| 切航線不重複下載 | 3 命中 routeCache（F-13/INT-05/E2E-16） |
