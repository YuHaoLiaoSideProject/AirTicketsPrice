## 2. 研究發現

### 2.1 華航網站架構

| 網域 | 狀態 | 說明 |
|------|------|------|
| `www.china-airlines.com` | ❌ 403 Akamai | 主站有強 bot 防護 |
| `flights.china-airlines.com` | ✅ 可訪問 | 第三方平台（airtrfx.com）託管 |
| `vg-api.airtrfx.com/graphql` | ⚠️ 需認證 | GraphQL API |

### 2.2 技術發現

1. **flights.china-airlines.com** 是由第三方平台 `airtrfx.com` 託管的訂票系統
2. 使用 **GraphQL API** (`vg-api.airtrfx.com/graphql`) 
3. API 需要認證（直接呼叫回傳 `UNAUTHENTICATED`）
4. **Playwright + xvfb** 可以成功載入首頁（狀態碼 200）
5. 表單互動複雜（React 狀態管理），需精確的事件觸發

### 2.3 嘗試過的方法

| 方法 | 結果 | 說明 |
|------|------|------|
| curl 直接呼叫 | ❌ 403 | Akamai 防護 |
| Playwright headless | ❌ 403 | Bot 檢測 |
| Playwright + xvfb | ✅ 200 | 可載入首頁 |
| GraphQL API 直接呼叫 | ❌ UNAUTHENTICATED | 需要認證 |
| 表單自動化 | ⚠️ 部分成功 | 值未正確寫入 React state |

## 3. 候選方案

### 🟢 方案 A：Playwright + xvfb 自動化（**建議**）

- 使用 Playwright 自動化 `flights.china-airlines.com`
- 需要 xvfb 環境（GitHub Actions 需安裝）
- 優點：可完整模擬瀏覽器操作
- 缺點：速度慢、需處理 React 狀態、維護成本高

### 🔵 方案 B：Google Flights 抓取

- 使用 Playwright 抓取 Google Flights 的華航票價
- 優點：資料格式統一、涵蓋多航空
- 缺點：需處理 URL 編碼、資料解析複雜

### 🟡 方案 C：第三方 API（SerpAPI / AviationStack）

- 使用付費 API 取得航班資料
- 優點：資料穩定、格式標準
- 缺點：需付費、免費額度有限

### 🔴 方案 D：直接呼叫華航 API（❌ 不可行）

- 華航主站有 Akamai 防護，無法直接呼叫
- flights.china-airlines.com 的 GraphQL API 需要認證

### 🟡 方案 E：第三方 API — Amadeus（免費方案）

| 項目 | 內容 |
|------|------|
| 免費額度 | 500 次/月（測試環境） |
| API | Flight Offers Search |
| 優點 | 官方 API、資料準確、無 bot 防護 |
| 缺點 | 需要註冊、有限制 |

```python
# 使用 Amadeus API
import requests

def search_flights(origin, dest, dep_date, ret_date):
    url = "https://api.amadeus.com/v2/shopping/flight-offers"
    headers = {
        "Authorization": f"Bearer {access_token}"
    }
    params = {
        "originLocationCode": origin,
        "destinationLocationCode": dest,
        "departureDate": dep_date,
        "returnDate": ret_date,
        "adults": 1,
        "max": 10
    }
    response = requests.get(url, headers=headers, params=params)
    return response.json()
```

### 6.2 核心程式碼骨架

```python
# fetch_ci_prices.py
import asyncio
from playwright.async_api import async_playwright

async def search_flights(origin, dest, dep_date, ret_date):
    async with async_playwright() as p:
        browser = await p.chromium.launch(
            headless=False,  # 需要 xvfb
            args=['--disable-blink-features=AutomationControlled']
        )
        context = await browser.new_context(
            viewport={'width': 1920, 'height': 1080},
            user_agent='Mozilla/5.0 ...',
            locale='zh-TW',
        )
        page = await context.new_page()
        
        # 1. 載入首頁
        await page.goto("https://flights.china-airlines.com/zh-tw")
        
        # 2. 填寫表單（需處理 React 狀態）
        await fill_form(page, origin, dest, dep_date, ret_date)
        
        # 3. 點擊搜尋
        await page.click('button[data-att="search"]')
        
        # 4. 提取結果
        results = await extract_results(page)
        
        await browser.close()
        return results
```
