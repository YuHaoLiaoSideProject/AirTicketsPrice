## 方案 3：第三方 API

### 可用 API

| API | 免費額度 | 價格 | 說明 |

## 結論

### 最佳方案
🟢 **Playwright + xvfb 自動化 flights.china-airlines.com**

### 理由
1. 官方資料來源，準確性高
2. 免費，無 API 限制
3. 可完整模擬瀏覽器操作

### 風險
- 表單互動可能不穩定
- 華航改版可能導致自動化失效
- 執行時間較長
